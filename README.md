# School Managment System

## Introduction

This is a full stack School Managment System that I developed using the MERN stack.The system helps to manage students,teachers,attendance and marks effciceintly.

---

## Features

- Role-based authentication
- Student managment
- Teacher,Admin and Student dashboard
- Secure login
- Attendance management
- Marks managment
- Responcive user interface

---

# Technologies used

### Frontend

- React.js
- Tailwind.css

### Backend

- Node.js
- Express.js
